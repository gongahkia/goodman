Safari Host App

Inline timezone conversion with explicit site access.

ONUL converts selected times and dates directly in the page. It defaults to manual conversion and only enables live inline conversion on websites you approve.

How it works

Use the extension popup or context menu to convert the current selection. Enable live conversion only for sites where you want instant inline results.

Privacy

ONUL does not transmit browsing data, selection text, or analytics off-device. Parsing and timezone conversion happen locally.

Safari setup

  1. Open Safari Settings from the button on the right.
  2. Enable ONUL in the Extensions section.
  3. Choose website access for the sites where you want live conversion.
  4. Use ONUL’s popup to convert a selection or enable live mode for the current site.
Extension Status

Turn on ONUL in Safari Settings, then grant website access for the sites you approve.
